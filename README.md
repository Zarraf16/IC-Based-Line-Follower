# IC-Based Line-Follower Robot

**IR sensing · Logic ICs · Motor control · Circuit assembly**

An individual electronics project by **Zarraf Alam Fahmid**: a line-following robot using IR sensors and logic ICs, without a microcontroller.

## How it works

IR sensing detects the track, and the hardware logic determines the motor response needed to follow the line. The control behavior is implemented in the circuit rather than in firmware.

## Project work

- Integrated IR sensing with logic-based motor control.
- Assembled and soldered the circuit.
- Tested the robot and debugged circuit connections.
